# DECISIONS.md

This file records all meaningful decisions made during the project.

---

## Decision Format

```
## DECISION-[NNN]

**Date:** YYYY-MM-DD
**Made by:** [User / Agency Director]

**Decision:**
[What was decided]

**Alternatives considered:**
[What was rejected and why]

**Reason:**
[Why this decision was made]

**Impact:**
[Which agents / what work is affected by this decision]

**Status:** APPROVED
```

---

*Decisions are added here as they are made. Closed decisions are not reopened unless new evidence provides a legitimate reason.*
