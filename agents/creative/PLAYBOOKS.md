# Creative / Visual Producer — PLAYBOOKS.md

This file contains practical operating models and repeatable processes.

## Playbook 1: Visual Concept Development

**Trigger:** Project brief received and strategy has been defined.

**Steps:**
1. Review brand guidelines (in GitHub) and strategy brief
2. Define the visual territory: mood, tone, subject matter, style reference
3. Develop 2–3 visual directions if brief allows
4. Create visual reference document (mood board or written description with specific references)
5. Define production requirements: equipment, locations, talent, budget estimate
6. Submit to Agency Director for internal review before user presentation

## Playbook 2: Production Planning

**Trigger:** Visual concept has been approved by user.

**Steps:**
1. Create detailed shot list or production brief
2. Document equipment requirements
3. Identify post-production requirements and delivery specs
4. Estimate timeline
5. Document file server paths where assets will be stored
6. Update project JOURNAL.md with production plan
