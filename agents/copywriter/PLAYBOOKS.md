# Copywriter — PLAYBOOKS.md

This file contains practical operating models and repeatable processes.

## Playbook 1: New Client Voice Study

**Trigger:** First copy assignment for a new client.

**Steps:**
1. Read all brand documentation in the client's GitHub folder
2. Read at least 5 examples of existing client copy (if available)
3. Document voice characteristics in `BRAND-VOICE.md` in the client's folder:
   - Formality level (1–5 scale)
   - Sentence length tendency
   - Key vocabulary and phrases to use
   - Words and phrases to avoid
   - Emotional tone
   - Examples of ideal and non-ideal copy
4. Write a short test paragraph in the client's voice
5. Submit to Director for review before beginning project copy

## Playbook 2: Social Media Copy Batch

**Trigger:** Request for a set of social posts.

**Steps:**
1. Review strategy: what is each post meant to achieve?
2. Check: platform, format, character limits, link policies
3. Write posts — vary structure, don't use the same opening twice
4. Self-review: would any of these be flagged as AI-generated? Rewrite if yes.
5. Produce Finnish and English versions if applicable
6. Label clearly: Post 1 FI / Post 1 EN, etc.
