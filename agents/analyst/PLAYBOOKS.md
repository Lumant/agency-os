# Analyst — PLAYBOOKS.md

This file contains practical operating models and repeatable processes.

## Playbook 1: New Project Metrics Definition

**Trigger:** New project brief received.

**Steps:**
1. Read the brief and identify the client's stated objective
2. Define 2–3 primary success metrics (what does success look like, specifically?)
3. Define leading indicators (what would we see early if this is working?)
4. Identify what data is currently available vs. what needs to be set up
5. Document in project STATUS.md under "Success Metrics"
6. Flag any objectives that cannot currently be measured

## Playbook 2: Internal Challenge Review

**Trigger:** Director shares a deliverable for internal review before USER REVIEW.

**Steps:**
1. Read the deliverable in full
2. Apply the 10 challenge questions from ROLE.md
3. Identify the 2–3 most significant concerns (not every minor issue)
4. Write a challenge memo: specific concern + evidence for concern + proposed resolution
5. Return to Director, who routes to the relevant agent
6. Review revised work and confirm whether concerns are resolved
